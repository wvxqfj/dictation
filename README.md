# Диктовка

Маленькое приложение в трее Windows: держите клавишу и говорите — текст печатается в любое окно. Работает без интернета.

## Установка

Откройте **PowerShell** (Пуск → набрать «PowerShell» → Enter), вставьте команду и нажмите Enter:

```powershell
irm https://raw.githubusercontent.com/wvxqfj/dictation/main/install.ps1 | iex
```

Установщик сам поставит Python (если его нет), библиотеки, ярлык «Диктовка» в меню Пуск и автозапуск с Windows, и запустит программу. Права администратора не нужны, всё ставится в `%LOCALAPPDATA%\Dictation`. При первом запуске скачаются модели (~500 МБ). Обновление — та же команда, настройки сохраняются.

Удалить: выключить «Запускать вместе с Windows» в настройках, выйти через меню трея, удалить папку `%LOCALAPPDATA%\Dictation` и ярлык «Диктовка» в меню Пуск.

## Как пользоваться

| Клавиши | Что делает |
|---|---|
| **Copilot** (держать) | Запись → текст на языке, на котором говорите |
| **Copilot** коротко нажать и сразу (в течение полсекунды) зажать | Запись → перевод на английский |
| Выделить текст, **Copilot** коротко нажать | Меню: переписать выделенное короче / длиннее / официальнее… |
| Выделить текст, **Copilot** дважды коротко нажать | Перевод выделенного на русский (русский текст — на английский) |

Нет клавиши Copilot — щёлкните по значку в трее → «Настройки» → «Клавиша диктовки», нажмите на поле, затем нужную клавишу (например, правый Ctrl) и «Сохранить».

Текст печатается прямо в активное окно по ходу речи. С моделью OpenAI `gpt-live-transcribe` (по умолчанию для OpenAI) слова появляются примерно через 0,3–0,5 с после того, как вы их произнесли, не дожидаясь паузы. Локальная модель тоже печатает по ходу речи (`local_streaming`): пока фраза не закончилась, она каждые ~0,3 с распознаётся заново, и печатаются слова, которые совпали в двух распознаваниях подряд, — отставание ~1 с; в конце фразы текст сверяется с финальным распознаванием. `gpt-4o-transcribe` печатает фразу целиком после паузы. Буфер обмена не используется.

По умолчанию распознавание **локальное** (модель GigaAM v3 от Сбера, работает без интернета и бесплатно): фраза в 4 с распознаётся за ~0,25 с на процессоре. Модель (~250 МБ) скачивается с HuggingFace при первом запуске, дальше грузится из кэша за ~3 с. Пока модель качается, а ключ OpenAI задан, диктовка временно идёт через OpenAI и сама переключается на локальную модель, как только та загрузится. Переключиться на OpenAI Realtime API можно прямо в меню трея (пункты «Локально» / «OpenAI») — тогда текст появляется ещё по ходу речи. Выбор запоминается в `config.json` (`"backend"`).

Перевод на английский по умолчанию тоже **локальный** (`"translate_engine": "local"`): модель OPUS-MT tc-big (Хельсинкский университет, русский/украинский/белорусский → английский) через CTranslate2, фраза переводится за ~0,1 с. Модель (~250 МБ) скачивается с HuggingFace при первом запуске, дальше работает без интернета. Перевод печатается по ходу речи: текущая фраза переводится заново целиком при каждом новом слове, на экран идут слова, совпавшие в двух переводах подряд, а в конце фразы хвост сверяется с переводом финального текста. Отставание ~1,5 с. Если фраза продолжает незаконченное предложение, модель продолжает уже напечатанный английский, а не переводит обрывок отдельно. Перевод через OpenAI (`"translate_engine": "openai"`) литературнее, но идёт короткими кусками (до запятой, каждые несколько слов или на паузе) и с отставанием ~1,5–2 с.

**Продолжение текста.** Перед началом диктовки программа смотрит, что уже стоит перед курсором (до 300 знаков, через UI Automation — работает в Блокноте, Word, браузерах и приложениях на Chromium/Electron). На стыке ставится пробел, если его нет, а если прошлое предложение не закончено (например, точку в конце прошлой диктовки программа сама не ставит), живая правка решает по смыслу: новая речь его продолжает — первое слово с маленькой буквы и без повтора («когда я нажимаю» + «Нажимаю на кнопку» → «когда я нажимаю на кнопку»), или начинает новое — прошлому предложению возвращается точка или знак вопроса. Если окно UI Automation не поддерживает, контекстом служит прошлая диктовка в этом же окне, пока вы в нём ничего не нажимали и не щёлкали. Этот текст уходит модели правки вместе с диктовкой (в OpenAI — если правка идёт через OpenAI).

**Переписать выделенное.** Выделите текст в поле ввода и коротко нажмите клавишу диктовки — рядом с выделением появится меню: «Длина» — *Короче*, *Чуть длиннее*, *Подробнее*; «Стиль» — *Официальнее*, *Свободнее*. Один щелчок — и выделенный текст заменяется переписанным (пока он готовится, кнопка пульсирует; обычно 1–3 с). Меню не забирает фокус, выделение в поле остаётся. Закрыть: Esc, щелчок мимо, любая клавиша или ещё одно короткое нажатие. Переписывает та же модель, что и живая правка (`cleanup_engine`, `cleanup_model`): через OpenAI, а без интернета — локальной Qwen (до 2 500 знаков за раз, качество заметно скромнее). Выделенный текст читается через UI Automation, а в окнах без неё — копированием (Ctrl+C), после чего прежнее содержимое буфера обмена возвращается. Многострочный результат вставляется через буфер обмена (так сохраняются абзацы), однострочный — печатается. В терминалах меню не открывается. Отменить замену — Ctrl+Z в самом приложении.

**Перевести выделенное.** Выделите текст на любом языке — сообщение от друга, абзац на сайте, письмо — и дважды коротко нажмите клавишу диктовки. Рядом с выделением появится пузырь: сначала «Перевожу…», через 1–3 с — перевод на русский (если выделен русский текст — на английский) и кнопка «Копировать». Текст в окне не меняется, так что переводить можно и то, что редактировать нельзя. Закрыть: Esc, щелчок мимо, любая клавиша или переключение окна. Переводит модель `translate_model` через OpenAI, а без интернета — локальная Qwen (до 2 500 знаков, качество скромнее). Выделение берётся через UI Automation, а если окно его не отдаёт — копированием (Ctrl+C) с возвратом прежнего буфера обмена. Расход учитывается в статистике как «Перевод».

Живая правка (убирает «э», «ну», оговорки, правит пунктуацию) по умолчанию работает в режиме **«авто»** (`"cleanup_engine": "auto"`): пока есть интернет и ключ — через OpenAI, ноутбук при этом не нагружается; если OpenAI не ответил за 5 с или нет сети — та же фраза правится локальной моделью Qwen3.5 2B через llama.cpp (родная ARM64-сборка, ~0,7 с на фразу). Связь перепроверяется раз в 20 с, и как только интернет вернулся — снова OpenAI. Локальная модель запускается только когда понадобилась и выгружается после 10 минут простоя. Сама llama.cpp (~12 МБ) и модель (~1,2 ГБ) скачиваются при первой надобности в `%LOCALAPPDATA%\Dictation` и кэш HuggingFace. Звуки-заминки («э-э», «эм») и паразиты между запятыми («это, короче, сложно») снимаются ещё до модели правилом. `"local"` — править всегда локально (модель держится в памяти, ~1,5 ГБ), `"openai"` — только через OpenAI.

Пока идёт диктовка, под камерой появляется индикатор в стиле Dynamic Island: чёрная капсула пружинисто раскрывается из точки, слева — микрофон, справа — волна голоса (красная; в режиме перевода — синяя и со значком EN). Сверху или снизу экрана — выбирается в настройках. После отпускания клавиши волна сменяется пульсацией — дописывается последняя фраза, — затем капсула сжимается в точку и исчезает. Посмотреть анимацию без диктовки: `python overlay.py`.

Микрофон держится открытым постоянно (на этом ноутбуке он включается ~0.5 с, и начало фразы терялось), поэтому Windows показывает значок микрофона. В эфир звук уходит только пока зажата клавиша. Отключить: `"keep_mic_open": false`.

## Ручная установка (для разработки)

```
pip install -r requirements.txt
```

1. Ключ OpenAI (`config.json` → `"openai_api_key"` или переменная `OPENAI_API_KEY`) нужен только для `"backend": "openai"`, `"translate_engine": "openai"` и правки через OpenAI. Без ключа и без интернета работают диктовка, перевод на английский и живая правка (локально).
2. Запуск: `start.bat`.
3. Автозапуск с Windows: `python dictation.py --install-autostart` (убрать: `--remove-autostart`).

## Окно «Настройки и статистика»

Открывается щелчком по значку в трее (или пунктом меню). Обычное окно Windows, светлая/тёмная тема — как в системе. При закрытии просто прячется, программа продолжает работать.

- **Статистика** — сколько времени сэкономлено, сколько потрачено на OpenAI (распознавание, живая правка, перевод), сколько слов надиктовано; графики по дням (наведите на столбик — подробности) и таблица. Период: сегодня / 7 / 30 дней / всё время.
- **Настройки** — всё основное из `config.json`. Большинство изменений применяется сразу; смена локальной модели требует перезапуска (в окне появится кнопка). Автозапуск с Windows включается переключателем.

Сэкономленное время = (знаков надиктовано ÷ ваша скорость печати) − время, пока была зажата клавиша. Скорость печати задаётся в настройках (`typing_cpm`, по умолчанию 200 знаков/мин).

Расходы считаются по токенам, которые возвращает OpenAI, и ценам из `stats.py` (если сервер не прислал токены — по длительности звука). Цены можно переопределить в `config.json`, например `"prices": {"gpt-4.1-mini": {"input": 0.4, "output": 1.6}}` ($ за 1M токенов). Данные лежат в `stats.json`, учёт идёт с момента установки этой версии.

## Настройки (`config.json`)

- `backend` — `local` (своя модель) или `openai`.
- `local_model` — локальная модель:
  - `gigaam-v3-e2e-rnnt` (по умолчанию) — лучший русский, с пунктуацией и «ё», самая быстрая; английские слова пишет как слышит.
  - `nemo-parakeet-tdt-0.6b-v3` — русский + английский и ещё 23 языка; по-русски ошибается чаще, в ~3 раза медленнее, ~1 ГБ памяти.
  - `gigaam-v3-e2e-ctc` — ещё чуть быстрее, качество немного ниже.
- `local_streaming` — печатать локально распознанный текст (и его перевод) по ходу речи (`true`) или фразой после паузы (`false`).
- `local_quantization` — `int8` (быстрее, меньше памяти) или пусто (полная точность).
- `transcribe_model` — модель распознавания OpenAI: `gpt-live-transcribe` (потоковая, текст по ходу речи, $0,017/мин ≈ $1/час удержания клавиши), `gpt-4o-transcribe` (по фразам, ~$0,36/час), `gpt-4o-mini-transcribe`.
- `live_delay` — для `gpt-live-transcribe`: `minimal` / `low` / `medium` / `high`. Меньше — текст быстрее, больше — точнее.
- `vad_silence_ms` — (локальная модель и `gpt-4o-transcribe`) какая пауза считается концом фразы (меньше — текст появляется быстрее, но фразы рвутся).
- `noise_reduction` — (только OpenAI) `near_field` (ноутбук/гарнитура), `far_field` или пусто.
- `keep_mic_open` — держать микрофон открытым (мгновенный старт).
- `mic_device` — имя микрофона, как в параметрах звука Windows; пусто — микрофон Windows по умолчанию. Удобнее выбрать в окне настроек.
- `cleanup` — живая правка вкл/выкл.
- `cleanup_engine` — где править: `auto` (OpenAI, а без интернета — локально), `local` или `openai`.
- `local_cleanup_model` — локальная модель правки: `qwen3.5-2b` (быстрая, ~1,5 ГБ памяти) или `qwen3.5-4b` (точнее, ~3 с на фразу, ~3 ГБ).
- `cleanup_model` — модель OpenAI для правки.
- `translate_engine` — где переводить на английский: `local` (своя модель, без интернета) или `openai`.
- `translate_model` — модель OpenAI для перевода при `"translate_engine": "openai"` (без ключа текст печатается без перевода).
- `language` — (только OpenAI) пусто = автоопределение; можно `"ru"`, чтобы принудительно.
- `transcribe_prompt` — (только OpenAI) подсказка для распознавания (термины, имена).
- `hotkey_vk` — код клавиши (134 = F23, её шлёт клавиша Copilot). Удобнее выбрать в окне настроек.
- `add_trailing_space` — пробел после надиктованного.

После изменения настроек — «Выход» в меню трея и запустить заново.

## Замечания

- Клавиша Copilot полностью перехватывается приложением, пока оно запущено (Copilot / Claude она больше не открывает).
- В окна, запущенные от администратора, ввод работает только если и диктовка запущена от администратора.
- Лог: `dictation.log`.
